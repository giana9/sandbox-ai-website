# Juniper & Crumb

A responsive custom-cookie storefront built with HTML, CSS, and JavaScript. AI was prompted: "Can you create 3 separate files based on this prompt: a cookie website (using html) that specializes in custom order cookies with a green website theme (using css) and a functional form users can fill out to request a special order cookie (with js)"

## Project files

- `index.html` contains the bakery storefront, cookie specialties, story section, and custom-order form.
- `styles.css` defines the green visual theme, responsive layouts, form styling, and reduced-motion support.
- `script.js` validates the order form, prevents selecting a past date, and displays an on-page confirmation after a valid submission.

## Run locally

Open `index.html` in a web browser.

## Order form note

The form currently runs entirely in the browser. It validates the required fields and displays a confirmation, but it does not send, save, or email orders. Connecting it to a bakery inbox or backend would be needed to receive real requests.
